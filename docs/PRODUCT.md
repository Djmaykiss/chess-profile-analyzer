# Producto

Chess Profile Analyzer permite a un usuario agrupar varias cuentas públicas de Lichess y Chess.com en perfiles ajedrecísticos privados. Las estadísticas y conclusiones deben derivarse de partidas reales.

El MVP cubre autenticación, perfiles, cuentas, importación, normalización, estadísticas, aperturas, partidas y dossier. Stockfish no bloquea el MVP.
